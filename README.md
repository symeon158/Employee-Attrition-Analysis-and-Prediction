# Employee Attrition Analysis and Prediction

This repository contains a project focused on analyzing and predicting employee attrition using advanced machine learning techniques. The project also provides data visualizations to gain actionable insights into employee turnover trends.

---

## 🔍 Project Overview

Employee attrition, or turnover, is a critical challenge for organizations. This project aims to:
- Analyze historical attrition data to identify key trends.
- Predict future attrition using machine learning models like XGBoost.
- Visualize attrition patterns over time and across various demographic and organizational dimensions.

---

## 📊 Features

- **Data Preprocessing**: 
  - Handles missing values, categorical data encoding, and feature engineering (e.g., `Tenure`, `Age`, and `Attrition`).
- **Advanced Machine Learning**:
  - Trains an XGBoost model using hyperparameter tuning to predict employee attrition.
  - Handles class imbalance with computed class weights.
- **Insightful Visualizations**:
  - Attrition trends over time, by department, gender, and tenure.
  - Advanced visualizations with annotations for year-over-year differences.
- **Explainability**:
  - Uses SHAP (SHapley Additive exPlanations) to identify features most correlated with attrition.
